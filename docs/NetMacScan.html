Description

Cross-platform LAN MAC address scanner for Delphi (FMX).

How it works per platform:
  Windows       : SendARP (iphlpapi.dll) for every host, run in parallel.
                  SendARP issues a real ARP request, so devices that ignore
                  ping are still found.
  macOS / Linux : Sends a 1-byte UDP datagram to every host. This forces the
                  OS to ARP-resolve each address. Then reads the kernel ARP
                  table (macOS: sysctl, falling back to "arp -an"; Linux:
                  /proc/net/arp). Hosts are processed in batches of 256 so
                  large subnets don't overflow the kernel neighbour table.
  Android / iOS : NOT POSSIBLE. Android 10+ and iOS 11+ block apps from
                  reading the ARP table. ScanNetworkMacs raises
                  ENotSupportedException there. Call MacScanSupported first.

If the ARP table cannot be read (recent macOS versions hide it from apps, even ones allowed on the local network), the scan raises an error rather than reporting an empty network; Tapo.Discovery then finds devices by TCP.

ANetwork : any address inside the network, e.g. '192.168.1.0' or '192.168.1.42' ASubnet : '255.255.255.0', '/24' or '24' 

Notes:
  - The scanning machine's own MAC is not included on macOS/Linux
    (the OS doesn't keep an ARP entry for itself).
  - Phones and laptops often use randomised "private" MACs per WiFi network.
  - macOS 15+: add NSLocalNetworkUsageDescription to the app's Info.plist
    (Project Options > Version Info), or local network traffic is blocked.
  - Linux FMX requires FMXLinux. macOS/Linux use Indy (ships with Delphi).

function MacScanSupported: Boolean;

True on platforms where MAC scanning is possible (Windows, macOS, Linux).

Returns

False on Android and iOS, which do not let apps read the ARP table.

function MacScanDiagnostics(const AProbeHost: string = ''): string;

Reports what the low-level calls the scan relies on return on this machine.

Covers popen, the ARP sysctl, "arp -an" and "netstat" on macOS, and /proc/net/arp on Linux; on Windows there is nothing to report. Use it to find out why a scan finds nothing. Takes up to a few seconds; safe on any thread.

Parameters
AProbeHost
A host to try a TCP connection to (ports 80 and 53). Empty: the default gateway on macOS; nothing on other platforms.
Returns

A multi-line report, for a log.

function ScanNetworkMacs(const ANetwork, ASubnet: string): TMacEntries;

Scans a subnet and returns every host that answered, with its MAC. Blocks.

Do not call it on the UI thread; use ScanNetworkMacsAsync. A typical /24 Wi-Fi network takes about 5 to 15 seconds.

Parameters
ANetwork
Any address in the network, for example '192.168.1.0'.
ASubnet
The mask: '255.255.255.0', '/24' or '24'.
Returns

The hosts found, in address order.

Exceptions raised
EArgumentException
The network or mask is not valid.
ENotSupportedException
The platform does not let apps read the ARP table.
EOSError
The ARP table could not be read.

TMacScanProgressEvent = procedure(Sender: TObject; Processed, Found, Total: Integer) of object;

Progress of a scan, in TNotifyEvent style. Always called on the main (UI) thread.

The first call is (0, 0, Total), so a progress bar can take its Max there; the last call before the completion callback is (Total, Found, Total).

Parameters
Sender
The ASender passed to the scan.
Processed
Addresses checked so far, 0 to Total.
Found
Matching hosts found so far: all hosts, or TP-Link hosts only for ScanTapoDevicesAsync.
Total
Addresses in the subnet, for example 254 for a /24.
