Description

Tapo cameras: C210, C220, C225, C325WB, C520WS, TC40, TC70.

TTapoDevice (abstract, Tapo.Client)
`-- TTapoCamera                 device info, pan/tilt, presets, RTSP URLs

Cameras log in over TPAP (HTTPS), or AES SSL if Third-Party Compatibility is on; Tapo.Client picks the protocol.

The RTSP URLs need the camera account (Tapo app > camera > Advanced Settings > Camera Account), which is separate from the Tapo cloud account. Snapshot capture is not included: it needs an RTSP/MJPEG client, which is outside the Tapo control API (open the MJPEG URL with any RTSP-capable player or library instead).
