Unit

Tapo.Client

Declaration

type TTapoChildDevice = class abstract(TTapoEndpoint)

Description

A device reached through a parent device: a power-strip socket or a sensor or switch paired to a hub.

Requests travel inside the parent's session, so a child device never logs in on its own. Obtain children from the parent (for example Strip.Outlet(1) or Hub.T31x('Kitchen')); the parent owns them.
