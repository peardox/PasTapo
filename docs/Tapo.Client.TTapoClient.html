Unit

Tapo.Client

Declaration

type TTapoClient = class(TObject)

Description

Your Tapo account, and the devices reached with it.

Give the account details once, then add each device by IP address. The client owns the devices and frees them when it is freed.

The user name and password are those of the Tapo app. TPAP devices use only the password; camera hubs use the password with their local "admin" account.

Example: 

uses Tapo.Client, Tapo.Models, Tapo.Devices;

Client := TTapoClient.Create('you@example.com', 'password');
try
  Plug := Client.Add(P110, '192.168.1.50');
  ShowMessage(Format('%.1f W', [Plug.GetCurrentPower]));
finally
  Client.Free;
end;

Public function AddDevice<T:TTapoDevice>(const AHost: string): T; overload;

Adds the device of class T at AHost, or returns the one already added there.

No network request is made until the device is first used.

Example: 

Plug := Client.AddDevice<TTapoP110>('192.168.1.50');

Parameters
AHost
The IP address, host name, or host:port.
Returns

The device, owned by the client.

Exceptions raised

Public function CloneEmpty: TTapoClient;

Creates a new client with the same account, protocol and timeouts, and no devices.

Use it for short-lived work that must not touch this client's devices, for example probing addresses with shorter timeouts during a network scan. A device found that way can be added to this client and given the probe's login with TTapoDevice.TakeSession.

Returns

The new client. The caller owns it and must free it.
