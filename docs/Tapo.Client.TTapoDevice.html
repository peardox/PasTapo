Unit

Declaration

type TTapoDevice = class abstract(TTapoEndpoint)

Description

A Tapo device reached by IP address: the base class of every device class. It picks the protocol, logs in, and keeps the session.

The device logs in on its first request and keeps the session. If the device ends the session, the next request logs in again once and is retried. A login rejected for wrong credentials is never retried, because TPAP devices lock themselves after repeated failures.

Requests to one device are serialised, so a device object may be shared between threads. All calls are blocking network I/O; call them from a background thread in an FMX application.

Create devices through the client (Client.Add(P110, ...), Client.AddDevice or Client.AddDetected), which owns them.

Picks the protocol and logs in now.

Optional: the first request logs in if this has not been called.

Exceptions raised
ETapoError
The login failed. ErrorCode -2101 means the device has locked itself after too many failed logins.
Public procedure Logout;

Forgets the session, so the next request logs in again.

The protocol is detected again too, in case a firmware update changed it.

Public procedure TakeSession(ASource: TTapoDevice);

Takes over the logged-in session of another object for the same device.

Device detection uses this so a detected device does not log in twice.

Parameters

An object for the same host, family and auth mode. It is logged out.
Exceptions raised
ETapoError
ASource is for another host or protocol family.
