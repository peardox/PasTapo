Tapo.Client

type TTapoDeviceInfo = record

Description

The fields every Tapo device reports in its device info.

Nickname and SSID are decoded from the Base64 the device sends. Cameras report some fields under other names (dev_id, sw_version, device_model, device_alias); FromJSON reads either. Fields a device does not report are empty or 0. Raw holds the whole reply for anything else.
