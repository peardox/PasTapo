Class TTapoEndpoint

Description
Hierarchy
Methods

Unit

Tapo.Client

Declaration

type TTapoEndpoint = class abstract(TObject)

Description

Anything that accepts Tapo requests: a device reached by IP address (TTapoDevice) or a device reached through another one (TTapoChildDevice).

The typed methods of the device classes cover everything the devices are known to support. Execute gives raw access to any other method.

Sends one request and returns its result.

Parameters

The method name, for example 'get_device_info'.

The params object. Ownership passes to this method. May be nil.
AStamp
Adds requestTimeMilis and terminalUUID, as the Tapo app does for set_device_info and the light effects.
Returns

The reply's result object, owned by the caller; an empty object if there was none.

Public function Execute(const AMethod: string; AParams: TJSONValue = nil): TJSONObject;

Calls any device method.

Example: 

R := Plug.Execute('get_device_usage');
try
  Memo1.Lines.Add(R.Format);
finally
  R.Free;
end;

Parameters
AMethod
The method name, for example 'get_device_usage'.
AParams
The params object. Ownership passes to this method; do not free it. May be nil.
Returns

The result object. The caller frees it.

Exceptions raised
ETapoError
The device returned an error.
See also
ExecuteRequest
Same as Execute, but AParams stays with the caller (a copy is sent).
ExecuteStamped
Same as Execute, but adds requestTimeMilis and terminalUUID to the request as set_device_info does.
