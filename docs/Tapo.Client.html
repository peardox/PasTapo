Description

Tapo local-network client: account credentials, device registry and the abstract device base class that handles authentication.

TTapoClient       - holds the Tapo account e-mail and password (given once)
                    and owns the devices created from it.
TTapoEndpoint     - anything that accepts Tapo requests.
TTapoDevice       - abstract device reached by IP address. Picks the
                    protocol, logs in on first use, keeps the session and
                    logs in again only when the device ends it.
TTapoChildDevice  - abstract device reached through a parent device: a
                    power-strip socket or a hub sensor/switch.

Protocols (chosen per device family, as the Rust crate does):
  plugs, bulbs, strips, H100  - TPAP if the device announces it, else KLAP
  cameras                     - TPAP over HTTPS, else AES SSL
  camera hubs (H200, H500)    - AES SSL, as the local "admin" account

Concrete device classes are in Tapo.Devices, Tapo.Hubs and Tapo.Cameras; Tapo.Models adds Client.Add(P110, '192.168.1.50').

Protocol code ported from https://github.com/mihai-dinculescu/tapo. All calls are blocking network I/O; call them from a background thread (TTask.Run) in an FMX app. Each device serialises its own requests, so one device object may be shared between threads.

Types

TTapoProtocol = (...);

The local protocol a device is spoken to with.

Values
  • tpAuto: Pick the protocol for each device (the default).
  • tpKlap: KLAP: older firmware, or any firmware with Third-Party Compatibility on.
  • tpTpap: TPAP: SPAKE2+ login and AES-CCM session; current firmware with Third-Party Compatibility off.
  • tpAesSsl: AES SSL: cameras and camera hubs.
TTapoDeviceFamily = (...);

The request format a device family uses.

Values
  • dfSmart: Plugs, lights, light strips, power strips and the H100 hub.
  • dfSmartCam: Cameras and camera hubs (H200, H500): every request is wrapped in a multipleRequest.
TTapoAuthMode = (...);

How a device class logs in.

Values
  • amNegotiate: Ask the device: TPAP if it announces it, otherwise KLAP.
  • amCamera: TPAP over HTTPS, otherwise AES SSL (cameras).
  • amCameraHub: AES SSL as the hub's local "admin" account (H200, H500).
