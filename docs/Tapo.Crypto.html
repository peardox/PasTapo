Description

Cryptography for the Tapo local protocols, in pure Pascal (RTL only): AES-128 (ECB block, CBC/PKCS#7, CCM), HMAC-SHA256, HKDF-SHA256, PBKDF2-HMAC-SHA256, P-256 arithmetic and the SPAKE2+ prover (RFC 9383).

Ported from https://github.com/mihai-dinculescu/tapo and checked against the RFC 9383 test vector and the crate's known answers; run TapoCryptoSelfTest to repeat those checks in your build.

Classes, Interfaces, Objects and Records

Name Description
Class ETapoCryptoError Raised when a cryptographic operation fails: a bad key length, invalid padding after decryption, or a device share that is not a point on P-256.
Record TSpakeProof The prover's side of a completed SPAKE2+ exchange (RFC 9383), as returned by SpakeProve.

function SpakeProve(const Credential: string; const Salt: TBytes; Iterations: Integer; const UserRandom, DeviceRandom, DeviceShare: TBytes): TSpakeProof;

Runs the prover side of SPAKE2+ (RFC 9383) on P-256 with SHA-256, HKDF-SHA256 and HMAC-SHA256, as the TPAP login does.

Parameters
Credential
The password transform the device asked for (for plugs, the SHA-1 hex of the password).
Salt
The device's dev_salt.
Iterations
The device's PBKDF2 iteration count.
UserRandom
The 32 random bytes sent in pake_register.
DeviceRandom
The device's 32-byte dev_random.
DeviceShare
The device's share (dev_share), a SEC1 point.
Returns

The share and confirmation to send, and the keys for the session.

Exceptions raised
ETapoCryptoError
DeviceShare is not a usable point on P-256.
