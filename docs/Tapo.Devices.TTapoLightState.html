Unit

Tapo.Devices

Declaration

type TTapoLightState = record

Description

Several light settings to send in one request.

Start from New and chain the With... functions; each returns a modified copy. Pass the result to TTapoColorLight.Apply.

Example: 

Bulb.Apply(TTapoLightState.New.TurnOn.WithBrightness(40).WithColor(tcCoral));
