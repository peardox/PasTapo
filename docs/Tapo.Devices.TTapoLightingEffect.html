Unit

Tapo.Devices

type TTapoLightingEffect = record

Description

A lighting effect for the L920 and L930 light strips.

Start from a preset (Preset), from scratch (New) or from JSON, then adjust with the With... functions; each returns a modified copy. The field names and meanings are those of the Tapo app.

Example: 

Strip.SetLightingEffect(TTapoLightingEffect.Preset(lepAurora).WithBrightness(60));

See also
TTapoL920.SetLightingEffect
Runs a lighting effect.
