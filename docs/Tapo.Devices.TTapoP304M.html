Description

Tapo P304M and P316M energy-monitoring power strip.

Example: 

Strip := Client.Add(P304M, '192.168.1.52');
for Socket in Strip.Outlets do
  Memo1.Lines.Add(Format('%s: %.1f W', [Socket.GetOutletInfo.Nickname, Socket.GetCurrentPower]));
