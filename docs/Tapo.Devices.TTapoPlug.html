Public function GetPlugInfo: TTapoPlugInfo;

Public function SetTimer(ADelaySeconds: Integer; ADesiredOn: Boolean): TTapoTimer;

Sets the countdown timer, replacing any existing one.

Parameters
ADelaySeconds
1 to 86400 (24 hours).
ADesiredOn
The state to switch to when the timer fires.
Returns

The timer, with the id the device assigned.

Exceptions raised
ETapoError
ADelaySeconds is out of range.
Public function GetTimer(out ATimer: TTapoTimer): Boolean;

Reads the countdown timer.

Parameters
ATimer
Receives the timer, if one is set.
Returns

False if no timer is set.

Public procedure ClearTimer;

Removes the countdown timer, if any.

Public function AddScheduleRule(const ARule: TTapoScheduleRule): TTapoScheduleRule;

Adds a schedule rule.

Parameters
ARule
The rule, built with the TTapoScheduleRule class functions.
Returns

The rule with the id the device assigned.

Exceptions raised
ETapoError
The rule is invalid, the device's rule list is full (-1802), or the rule conflicts with another (-1803).
Public procedure EditScheduleRule(const ARule: TTapoScheduleRule);
