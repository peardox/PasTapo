type TTapoSegmentEffect = record

Description

A segment effect for the L920 and L930 light strips.

Start from a preset (Preset), from scratch (New) or from JSON, then adjust with the With... functions. A custom effect needs segments, states and a type.

Example: 

Strip.SetSegmentEffect(sepSunny);

See also
TTapoL920.SetSegmentEffect
Applies a segment effect.
