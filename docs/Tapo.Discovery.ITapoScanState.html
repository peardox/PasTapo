Interface ITapoScanState

Hierarchy
Methods

Unit

Tapo.Discovery

Declaration

type ITapoScanState = interface(IInterface)

Description

Internal: shared between a scanner and the work it started.

Queued callbacks hold this, not the scanner, so a scanner freed while a scan is under way is never called back.
