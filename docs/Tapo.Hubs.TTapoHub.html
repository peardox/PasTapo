Class TTapoHub

Hierarchy

Unit

Tapo.Hubs

Declaration

type TTapoHub = class abstract(TTapoDevice)

Description

The features common to the hubs: the sensors and switches paired to them.

Example: 

Hub := Client.Add(H100, '192.168.1.53');
Info := Hub.T31x('Kitchen').GetT31xInfo;
Label1.Text := Format('%.1f C, %d%%', [Info.CurrentTemperature, Info.CurrentHumidity]);

Public function Children: TArray<TTapoHubChild>;

Every paired device, each as its own class.

Use is to tell them apart (for example if C is TTapoT31x). A model this unit does not know comes back as a plain TTapoHubChild.
