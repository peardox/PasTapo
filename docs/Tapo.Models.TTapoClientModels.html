Class TTapoClientModels

Description
Hierarchy
Methods

Unit

Tapo.Models

Declaration

type TTapoClientModels = class helper(TObject) for TTapoClient

Description

Adds Add(Model, Host) and device detection to TTapoClient.

Each model constant has its own type, so the compiler picks the overload of Add that returns the right class: Client.Add(P110, ...) returns a TTapoP110 with no cast.

Public function AddDetected(const AHost: string): TTapoDevice; overload;

Logs in to AHost, reads its device info and adds it as the matching class.

Port 80 is tried first (plugs, lights, strips, H100), then port 443 as a camera and then as a camera hub. The probe's login is handed to the new device, so each device is logged in to once.

A camera hub may count one failed login when it is tried as a camera first. Do not rescan the same addresses in a tight loop.

Parameters
AHost
The IP address, host name, or host:port.
Returns

The device, owned by the client and already logged in; the existing device if AHost was already added.

Exceptions raised
ETapoError
AHost is not a Tapo device these credentials can log in to. ErrorCode -2101 means the device has locked itself after too many failed logins.
ETapoAuthError
A Tapo device rejected the account e-mail or password.
ETapoNoResponse
Nothing answered on port 80 or 443.
ETapoUnsupportedModel
A Tapo device of a model that is not supported.
See also
TryAddDetected
Same as AddDetected, without exceptions, for scanning a network.

Public function TryAddDetected(const AHost: string; out ADevice: TTapoDevice; out AError: string): Boolean;

Same as AddDetected, without exceptions, for scanning a network.

Example: 

Client.ConnectionTimeout := 500;
for I := 1 to 254 do
  if Client.TryAddDetected('192.168.1.' + IntToStr(I), Dev, Err) then
    Memo1.Lines.Add(Dev.Host + ': ' + Dev.ClassName);

Parameters
AHost
The IP address, host name, or host:port.
ADevice
Receives the device, or nil.
AError
Receives the reason when the result is False.
Returns

True if a supported Tapo device was found and added.
