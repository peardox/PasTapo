The request format the device answered in.

The class the device was added as.

Public MatchedBy: string;

How the class was chosen: 'model' (an exact match), 'model prefix' (for example P110 for a reported 'P110(EU)'), 'device type' (an unknown model, placed by its type and the fields it reports), or 'registered' (the address had already been added).
