Description

Model tags for TTapoClient.Add, so a device is added by its model name.

Plug  := Client.Add(P110, '192.168.1.50');    // TTapoP110
Bulb  := Client.Add(L530B, '192.168.1.51');   // TTapoL530
Strip := Client.Add(P304M, '192.168.1.52');   // TTapoP304M
Hub   := Client.Add(H100, '192.168.1.53');    // TTapoH100
Cam   := Client.Add(C210, '192.168.1.54');    // TTapoCamera

Each tag is a typed constant of its own record type, so the compiler picks the overload that returns the right class. If a tag name clashes with an identifier of your own, qualify it: Tapo.Models.P110.

Add(AModelName: string, ...) does the same at run time, from a model name such as one read from a configuration file.

AddDetected(AHost) needs no model at all: it logs in, reads the device info and adds the device as the matching class - for network scanning: 

if Client.TryAddDetected('192.168.1.60', Dev, Err) then
  if Dev is TTapoP110 then ...

Parameters

function TapoDeviceClassForInfo(const AInfo: TTapoDeviceInfo; AFamily: TTapoDeviceFamily; out AMatchedBy: string): TTapoDeviceClass;

Finds the device class for reported device info.

Parameters
AInfo
The device info, from TTapoDevice.GetDeviceInfo.
AFamily
The request format the device answered in.
AMatchedBy
Receives 'model', 'model prefix' or 'device type'; empty if no class was found.
Returns

The class: by model, by model prefix, or failing those by device type and the fields reported; nil if unknown.
