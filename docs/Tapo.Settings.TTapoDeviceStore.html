Public function Merge(const AResult: TTapoScanResult): Integer;

Adds the Tapo devices of a scan; never removes any.

A device is matched by its ID first, then by address. A match has its address, MAC, model, name and class refreshed; anything else is added. Devices the scan did not find are kept as they are.

Parameters
AResult
A scan result.
Returns

How many devices were new.

Public function AddToClient(AClient: TTapoClient; out ASkipped: TArray<string>): TArray<TTapoDevice>;

Adds every stored device to a client, as its stored class.

Nothing is sent to the devices: each one logs in on its first request. CheckDevice is the quick check of one.

Parameters
AClient
The client.
ASkipped
Receives one line per device that could not be added.
Returns

The devices, in store order; nil where a device could not be added.

Public function CheckDevice(AIndex: Integer; ADevice: TTapoDevice; out AMessage: string): TTapoCheckStatus;

Checks that a stored device is still where it was. Do not call it on the main thread.

Logs in if needed and reads the device info: one or two requests. Records the result, the time and any new name in the store, but does not save it. Safe to call for several indexes from different threads at once.

Parameters
AIndex
The device's position in Devices.
ADevice
The device object for it, from AddToClient; may be nil.
AMessage
Receives a short description of the result.
Returns

What was found.
