Unit

Tapo.Settings

Declaration

type TTapoSettings = class(TObject)

Description

The contents of settings.json.

Every public property is written to the file by Neon. Use Load and Save; FileName says where it lives.

Methods

Public constructor Create;

Creates empty settings: no account, network and subnet blank, state csUnknown.

Public class function FileName: string;

The full path of settings.json.

Returns

A path in the platform's per-user application data folder.

Public class function Exists: Boolean;

True if settings.json exists.

Returns

False on first run.

Public function Load: Boolean;

Reads settings.json into this object.

Returns

False if the file does not exist or cannot be read; the object then keeps its values.

Public procedure Save;

Writes this object to settings.json, creating the folder if needed.

Exceptions raised
EInOutError
The file could not be written.
Public function HasLogin: Boolean;

True if a user name and password are set.

Public function HasValidNetwork: Boolean;
