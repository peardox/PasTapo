Description

State that lasts between sessions, stored as JSON with Neon (https://github.com/paolo-rossi/delphi-neon@).

settings.json  the Tapo account, the network to scan, and whether the
               account worked the last time it was used
devices.json   every Tapo device a scan has found

Both live in the per-user application data folder of the platform: 

Windows  %LOCALAPPDATA%\TapoScan
macOS    ~/Library/Application Support/TapoScan
Linux    $XDG_CONFIG_HOME/TapoScan, or ~/.config/TapoScan

(set TapoAppFolderName before first use to change "TapoScan").

Files are written to a temporary file first and then renamed, so a crash never leaves half a file. On macOS and Linux they are readable by the owner only. The password is stored as plain text for now.

Scans only ever add to devices.json: a device that is not found again is kept. A device found at a new address (same device ID) has its address updated.

function TapoLocalNetwork(out ANetwork, AMask: string): Boolean;

Finds this computer's local IPv4 network.

Asks the system which local address it would use to reach the internet (a UDP socket is pointed at a public address; nothing is sent) and takes that adapter's mask. Without a route it falls back to the adapter list, preferring 192.168.x.x over 10.x.x.x over 172.16-31.x.x and skipping recognisable virtual adapters.

Parameters
ANetwork
Receives the network address, for example '192.168.1.0'.
AMask
Receives the subnet mask, for example '255.255.255.0'.
Returns

True if a private (LAN) IPv4 address was found; otherwise False and '192.168.0.0' / '255.255.255.0'.

Types

TTapoCredentialState = (...);

Whether the stored Tapo account details have been shown to work.

Values
  • csUnknown: Not tried yet: no scan has finished since they were entered.
  • csGood: A Tapo device accepted them.
  • csBad: Tapo devices rejected them and none accepted them.
TTapoCheckStatus = (...);

The result of checking one stored device at startup.

Values
  • tcsOk: It answered, and it is the device that was stored.
  • tcsDifferentDevice: It answered, but with another device ID: something else has that address now.
  • tcsBadCredentials: It answered but rejected the Tapo account.
  • tcsUnreachable: Nothing answered, or it could not be logged in to.
  • tcsNotLoaded: Its class could not be found, so it was not added.
